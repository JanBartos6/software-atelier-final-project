CSS/HTML Setup Guide

a brief document on how to use this page to build your article pages

This is your template page; all custom layouts and components must be placed within the <main> container, preferably using the <section class="article-section"> container.

Read on to discover the steps required to set up a new article, along with a few useful tips.

by Andrea Dell'Agnello and Alessandro Rohrwasser

How to set up a new article

  1. If you haven't already, create a folder within the contributors directory and name it using your first and last name (e.g., name_surname); all custom CSS files and images related to your articles should be placed inside this folder.
  2. Go to the html folder, make a copy of the article-template.html file and rename it using the main title of your article (e.g. history-of-ai.html).
  3. Open the newly created HTML file and enter your article title in the relevant <head> tag (e.g. <title>History of AI - AI in Everyday Life</title>).
  4. Add a link to your custom external CSS file using the <link rel="stylesheet" href="../css/your-css.css"> tag, or insert your CSS directly within the <style> tag already present in the file.
  5. Add the page description in the appropriate meta tag, once again in the document <head>.
  6. Modify the value of --template-color to reflect your main topic. The defined possible values are var(--first-main-topic-color), var(--second-main-topic-color), or var(--third-main-topic-color). If you wish to use a different color (in hexadecimal or rgb/rgba format), replace the entire var() expression with your desired value.
  7. Fill the title, subtitle, description and author fields within the <article-title> section.
  8. Add links to the previous and next articles, following the instructions provided in the reference document. You can search for PREVIOUS ARTICLE LINK and NEXT ARTICLE LINK to find what you need to replace.

Random useful tips

Little to no CSS is defined within <main>. You are essentially free to do as you please, but try to maintain consistency with the overall design of the website.

Before using a native HTML tag in your layout, search the existing markup code to check whether it has already been used. If it is already present, you can reuse it, but make sure to choose a unique ID or an available class.

The only "reserved" tag is, in essence, the <H1> tag, which is used for the main title of the page.

If you notice any neon-green text or element on the page, it is sign a placeholder from the template is still active; you should replace it with the relevant information.

In the css folder of the project, you will find the definitions.css file. It contains all the project's global variable definitions. You can use this file as a reference if you wish to apply the styles contained within it.

If you would like to use an image as a background for the article title section, you can override background-image in the #article-title selector.

We are always available to discuss any questions or feedback regarding the CSS, so please don't hesitate to reach out!
